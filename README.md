# 🏰 SiegeGuard — 3D 塔防游戏

基于 **Three.js** 的 3D 塔防游戏，在立体战场上布置防御塔，抵御一波波敌人的进攻！

**[👉 点此打开 在线即玩](https://is-cau.github.io/SiegeGuard/)**

---

## 🎮 玩法

- **选择防御塔**：点击底部面板中的塔（或按键盘 `1` `2` `3` `4`）
- **放置塔**：点击地图上的绿色格子放置塔
- **开始波次**：点击右下角按钮（或按空格键）
- **出售塔**：右键已放置的塔（返还 50% 金币）
- **旋转视角**：右键拖拽旋转 | 滚轮缩放
